# CaridoSense 🫀

CaridoSense is an AI-powered Heart Disease Prediction Web Application 
built using FastAPI and Machine Learning.

## Features
- 🫀 Predicts heart disease risk based on patient health data
- 📊 Visual risk analysis with charts and health indicators
- 💡 Personalized health tips based on prediction results
- ⚡ Fast and responsive web interface

## Tech Stack
- **Backend:** FastAPI, Python
- **ML Model:** Scikit-learn
- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** Render

## How to Run Locally
1. Clone the repository
   git clone https://github.com/santhoshere/cardiosense.git
2. Install dependencies
   pip install -r requirements.txt
3. Run the app
   uvicorn main:app --reload
4. Open http://localhost:8000
